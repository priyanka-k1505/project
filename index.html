How it works

From scan to result in three steps

No setup, no specialist software. Create an account and you are one upload away from a prediction.

STEP 01

Upload the ultrasound

Drag in a JPG or PNG kidney ultrasound. The image is processed in memory and is not stored.

STEP 02

The graph network reads it

EfficientNetV2 extracts patch features, then a similarity graph links related regions of the kidney.

STEP 03

Get a clear verdict

See Stone or Normal alongside the probability of each class, so you know how certain the model is.

Powered by

ASGCN-EffNetV2

An Adaptive Similarity Graph Convolutional Network on an EfficientNetV2-S backbone. It outperformed Vision Transformer, MobileNetV3 + GCN and InceptionNeXt + GCN on every metric.

  • Adaptive k-NN graph built from cosine similarity of patch features
  • Residual GCN blocks to avoid over-smoothing
  • Cross-attention fusion of local and graph-level features
